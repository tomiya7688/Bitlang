# Bitlang Preprocessed

Bitlang Preprocessed is an independent language layer generated from Bitlang by the preprocessor.
It is not a syntax mode or sub-specification of user-facing Bitlang.

The language has its own grammar, semantic rules, compiler-facing rules, tests, and documentation.
Only explicitly defined translation rules connect Bitlang to Bitlang Preprocessed.

See `LANGUAGE_SPEC.ja.md` for the current confirmed specification.
